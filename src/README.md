# Readable dashboard source

`app.readable.js` and `app.readable.css` are the readable sources behind the byte-budgeted files in
`dashboard/`. The entry loads only `dashboard/index.html`, `dashboard/app.css` and `dashboard/app.js`;
the copies here are kept for review and for matching the build transcript. They are not copied to
`/output` and are not part of the dashboard's measured source.
